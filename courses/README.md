# Course content

Path pattern:

```
courses/{vertical}/{track}/{level}/lesson-XX/
  README.md      # Lesson narrative (markdown)
  exercise.*     # Starter code
  quiz.json      # Quiz definition
  meta.yaml      # title, duration_min, video_youtube_id, tier
```

Examples:

- `courses/programming/python/beginner/lesson-01/`
- `courses/islamic-studies/basic/lesson-01/`
- `courses/age-groups/elementary/coding-blocks/lesson-01/`

Levels: `beginner` | `intermediate` | `advanced` (or `basic` for non-CS verticals).
